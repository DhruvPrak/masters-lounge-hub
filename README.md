# Dehradun Lounge Design

Create a modern, visually striking website for "Masters Snooker and Gaming Club" — a premium snooker, pool, and gaming lounge located in Dehradun, Uttarakhand (rated 4.8★ with 95 reviews on Google).



BRAND FEEL:

Dark, moody, premium lounge aesthetic — like an upscale pool hall/gaming bar. Think deep charcoal/black backgrounds with a rich accent color (emerald green, inspired by the snooker table felt) plus a warm gold/amber highlight for CTAs and accents. Clean modern sans-serif typography, generous spacing, subtle glow/shadow effects on cards.



PAGES/SECTIONS (single-page scroll site):



1. Navbar — Sticky top nav with logo/name on left, links (Home, Gallery, About, Booking, Contact) in center/right, and a light/dark mode toggle switch on the far right. Default to dark mode.



2. Hero Section — Full-width hero with a snooker table background image/overlay, club name as bold headline, tagline like "Where Precision Meets Play", subtext mentioning Snooker, Pool, PS5, Xbox & VR gaming, and a prominent "Book a Table" CTA button.



3. Info/About Section — Short paragraph about the club, plus icon-based feature cards: Snooker & Pool Tables, PS5/Xbox/VR Gaming, Food & Beverages (Master's Kitchen), Open Daily till 10 PM. Include the 4.8★ rating with 95 reviews displayed prominently.



4. Gallery/Album Section — Responsive grid/masonry photo gallery showcasing the snooker tables, gaming setup, interior, and club ambience. Lightbox-style click-to-enlarge on images.



5. Booking Section — A clean booking form: Name, Phone Number, Date picker, Time slot selector, Table type (Snooker/Pool/Gaming Console), Number of hours, and a "Confirm Booking" button. Show a simple visual of available/unavailable slots if possible.



6. Contact/Location Section — Address: New Canal Rd, near Bangali Kothi Road, Doon University Campus, Kedarpur, Dehradun, Uttarakhand 248001. Phone: 097605 04060, WhatsApp button, embedded Google Maps, and social media icons (Instagram).



7. Footer — Club name, quick links, contact info, copyright line.



DESIGN NOTES:

- Fully responsive (mobile-first, since most visitors will view on phone via WhatsApp links)

- Smooth scroll animations, hover effects on cards/buttons

- Light mode: switch to soft white/cream background with the same green/gold accents, keeping brand consistency

- Use rounded corners, soft shadows, and modern card-based layouts throughout
